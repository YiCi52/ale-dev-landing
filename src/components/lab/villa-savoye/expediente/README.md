# EXPEDIENTE — Villa Savoye (fase 0 del PLAN-OBRA)

Una ficha por nivel, con sus recintos. Cada dato lleva su fuente entre corchetes: `[S3]` = fuentes.md.

**Estados de cada dato**
- ✅ **confirmado** — dos fuentes independientes, o una primaria (plano FLC, foto fechada).
- ⚠️ **contradictorio** — las fuentes no coinciden; se anota cuál dice qué. No se modela hasta resolverlo.
- ❓ **sin fuente** — no se pone. Si hace falta para que el recinto se lea habitado, va a
  `decisiones.md` y **Alejandro decide**.
- 👁 **por ver en fotos** — el texto lo menciona pero falta verlo (forma, color, posición).

**Regla**: nada entra al modelo (fases 2–5) sin estado ✅, o ⚠️/❓ resuelto en `decisiones.md`.

Archivos: `fuentes.md` · `promenade.md` · `nivel-0-planta-baja.md` · `nivel-1-principal.md` ·
`nivel-2-solarium.md` · `jardin.md` · `decisiones.md`
